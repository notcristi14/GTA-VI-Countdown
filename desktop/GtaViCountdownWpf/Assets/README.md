# GTA VI logo (exe icon)

`GtaLogo.ico` is the **GTA VI logo** used as the Windows executable icon for the **C++ launcher** (`launcher/`).

The old WPF desktop project has been removed. This folder only keeps the shared `.ico` asset so CMake can embed it into `GtaViCountdown.exe`.

You may instead place a copy at `launcher/assets/GtaLogo.ico`.
