# Launcher assets

| File | Role |
|------|------|
| **`GtaLogo.ico`** | GTA VI logo — Windows **executable icon** (taskbar, Explorer, Alt+Tab). Embedded via `src/app.rc` as `IDI_APPICON`. |

Do not remove `GtaLogo.ico` if you want a branded `.exe`.
