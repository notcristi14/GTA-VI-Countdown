# GTA VI Countdown — desktop launcher (C++)

Win32 + **WebView2** shell that embeds the live countdown site.

## Features

- Loads the live site in WebView2
- Toolbar: Back · Forward · Home · Refresh
- **GTA VI logo** as `.exe` icon when GtaLogo.ico is embedded

See [root README](../README.md). Assets: [launcher/assets/README.md](assets/README.md).

## Requirements

- Windows 10/11 · Visual Studio 2022 (C++) · WebView2 Runtime

## Build

1. Open `GtaViCountdown.sln`
2. Restore NuGet · Release | x64 · Build
3. Run `bin\x64\Release\GtaViCountdown.exe`
